## Sanctions par niveau de score

| Score | Statut | Action |
|---|---|---|
| 80-100 % | Conforme | Bonus visibilité réseau |
| 60-79 % | À surveiller | Plan d'action 30 jours |
| 40-59 % | Non conforme | Mise en demeure + accompagnement forcé |
| < 40 % | Critique | Retrait de licence + exclusion réseau |
| Violation FREK-ID | — | Retrait immédiat, indépendamment du score |
